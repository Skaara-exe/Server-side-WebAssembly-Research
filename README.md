This repository is a collection of all work and research done by myself and 2 other KDG students. 

You can find more general information including an [opening article](https://skaara-exe.github.io/Server-side-WebAssembly-Research/pages/article_page.html), our [research paper](https://skaara-exe.github.io/Server-side-WebAssembly-Research/pages/research_paper_page.html), [teachers slides](https://skaara-exe.github.io/Server-side-WebAssembly-Research/pages/teaching_slides.html) you can use to as a one lesson introduction to serverside wasm, and all the rest [here](https://skaara-exe.github.io/Server-side-WebAssembly-Research/)


[/demos](https://github.com/Skaara-exe/Server-side-WebAssembly-Research/tree/main/demo) are 3 small projects that we used to show of possibilities during our presentation.

[/containers](https://github.com/Skaara-exe/Server-side-WebAssembly-Research/tree/main/containers) was with the focus on using wasm in containers (docker/kubernetes).

[/experiments](https://github.com/Skaara-exe/Server-side-WebAssembly-Research/tree/main/experiments) has a couple examples of api endpoints with one example of how using a vision encoder model typicaly ran in python.

[/hello_world_tests](https://github.com/Skaara-exe/Server-side-WebAssembly-Research/tree/main/hello_world_tests) is collection of hello world examples using the guest and host implementation (cross language promise)

This is student research in a growing technology so don't take the these conclusions as truth. we put sources in the reseach paper and ocasionaly in the code readme's, so please read up on it yourself aswell if you are interested.

If you have any questions feel free to reach out (primary contact is Skaara). And let us know if you ever make some cool stuff with the tech!!
